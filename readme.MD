# JPEG Scrambler
A tiny application that randomizes the order of a JPEG's binary data by randomizing a configurable amount of slices.

Written in python using the tkinter library.

I got inspired by this idea after syncthing paused mid-image and it turned into this cooler version of the same photo :3
